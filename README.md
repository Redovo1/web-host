# WebHostMost 自动保号脚本

> 一个每月自动帮你登录 [WebHostMost](https://client.webhostmost.com) 免费虚拟主机的脚本，防止账号因长期不登录被删除。

## 这是什么？

WebHostMost 提供免费的虚拟主机，但要求用户**定期登录**，否则账号会被删除（俗称"保号"）。

这个项目的作用是：**每月 11 号自动帮你登录一次**，你什么都不用管，也不用记着去登录。

- ✅ 支持多个账号一起保号（最多 10 个）
- ✅ **一个账号一个设置**，加新账号不影响老的
- ✅ 完全免费（用 GitHub Actions 跑，不用自己的电脑）
- ✅ 登录失败时 GitHub 会发邮件通知你

## 保姆级配置教程

跟着做就行，全程大概 **5 分钟**。

### 第 0 步：准备一个 GitHub 账号

如果你还没有 GitHub 账号：

1. 打开 [https://github.com/signup](https://github.com/signup)
2. 填邮箱、设置密码、起个用户名
3. 去邮箱收验证码，完成注册

已经有账号就跳过这步。

---

### 第 1 步：把这个项目复制到你自己的账号下（Fork）

"Fork" 的意思就是**把别人的项目复制一份到你自己的 GitHub 账号**，这样你就能自己用。

1. 打开项目地址：[https://github.com/Redovo1/web-host](https://github.com/Redovo1/web-host)
2. 看页面**右上角**，找到一个写着 **"Fork"** 的按钮，点它
3. 在新打开的页面上，直接点绿色的 **"Create fork"** 按钮（什么都不用改）
4. 等几秒钟，页面会自动跳转到**你自己账号下的** `web-host` 项目

> 怎么确认成功了？看页面左上角，如果显示的是 `你的用户名/web-host`，就说明 fork 成功了。

---

### 第 2 步：添加你的 WebHostMost 账号

**这里是重点**：**一个账号创建一个 Secret**，以后加新账号只需要新建一个 Secret，不用动老的。

#### 添加第 1 个账号

1. 在你刚 fork 的仓库页面，点**最上面一排标签**里的 **"Settings"**（设置，在最右边）
2. 看**左侧菜单**，找到 **"Secrets and variables"** 点开 → 再点下面的 **"Actions"**
3. 点页面中间绿色的 **"New repository secret"** 按钮
4. 填两个输入框：
   - **Name**（名字）：填 `WEBHOST_1`（注意全大写，中间是下划线）
   - **Secret**（值）：填 `邮箱:密码`

   **举例**：假设你第一个账号邮箱是 `zhangsan@gmail.com`，密码是 `abc123`，那 Secret 框里就填：
   ```
   zhangsan@gmail.com:abc123
   ```
   （邮箱和密码中间是**英文冒号** `:`）

5. 点绿色的 **"Add secret"** 按钮保存

#### 以后想加第 2 个账号

重复上面的步骤，**只把名字改成 `WEBHOST_2`**，填上第 2 个账号的 `邮箱:密码`，保存就行。

老的 `WEBHOST_1` 完全不用动。

#### 以后想加第 3 个、第 4 个……

一样的套路，名字依次用 `WEBHOST_3`、`WEBHOST_4`……最多支持到 `WEBHOST_10`。

#### 删除某个账号

去 **Settings → Secrets and variables → Actions**，找到对应的 `WEBHOST_几`，点右边的垃圾桶图标删除即可，不影响其他账号。

> ⚠️ 小贴士：密码里最好**只用字母和数字**，避免有 `:` 冒号或空格引起的问题。如果你的密码里有冒号，建议去 WebHostMost 改个简单点的。

---

### 第 3 步：给脚本"写入"权限

脚本每次跑完要在仓库里留个时间戳记录（防止 GitHub 60 天不动就禁用 Actions），所以要给它写入权限。

1. 还是在 **Settings** 页面
2. 左侧菜单点 **"Actions"** → 下面的 **"General"**
3. 滚动到页面**最下面**，找到 **"Workflow permissions"** 这一栏
4. 选择 **"Read and write permissions"**（读和写权限）
5. 点下方的 **"Save"** 按钮保存

---

### 第 4 步：开启 Actions（定时任务）

1. 点最上面一排标签里的 **"Actions"**
2. 如果看到一个黄色的提示说 workflow 被禁用了，点绿色的 **"I understand my workflows, go ahead and enable them"** 按钮启用
3. 如果没看到提示，就说明已经启用了

---

### 第 5 步：手动跑一次，测试能不能用

不用等到 11 号，先手动跑一次看看：

1. 还在 **Actions** 页面，**左侧**会看到一个叫 **"Run Login Script"** 的任务，点它
2. 页面右边会出现一个 **"Run workflow"** 的灰色按钮，点一下
3. 弹出小框，直接点里面的绿色 **"Run workflow"** 按钮
4. 等大概 **1-2 分钟**，刷新一下页面
5. 看任务状态：
   - ✅ **绿色对勾**：所有账号登录成功，配置完成！
   - ❌ **红色叉**：有账号登录失败，点进去看详情

**怎么看详细日志？**

1. 点那次任务的标题进去
2. 点左边的 **"login"**
3. 展开 **"运行登录脚本"** 这一步
4. 能看到每个账号的登录结果，比如：
   ```
   共发现 2 个账号，开始逐个登录...

   账号 `zhangsan@gmail.com` 登录成功 ✅
   账号 `lisi@qq.com` 登录失败: Invalid email or password
   ```

---

### 第 6 步：就这样了，以后不用管

配置完就结束了。之后每月 **11 号**会自动登录一次（北京时间 11:22 左右）。

**想收到失败通知？** GitHub 默认就会发邮件，如果没收到可以检查：

1. 点**右上角自己头像** → **Settings**
2. 左侧 **"Notifications"**
3. 找到 **"Actions"**，确保邮件通知是打开的

## 常见问题

### Q: 我已经设好 WEBHOST_1 了，怎么加第 2 个账号？

去 **Settings → Secrets and variables → Actions → New repository secret**，名字填 `WEBHOST_2`，值填新账号的 `邮箱:密码`，保存。**WEBHOST_1 不用动。**

### Q: 我想删掉某个账号不保了，怎么办？

去 **Settings → Secrets and variables → Actions**，找到对应的 `WEBHOST_几`，点垃圾桶图标删除即可。

### Q: 我想修改某个账号的密码怎么办？

去 **Settings → Secrets and variables → Actions**，找到对应的 `WEBHOST_几`，点右边的**铅笔图标（Update）**，重新填一遍 `邮箱:新密码`，保存。

### Q: 10 个不够用怎么办？

找我（或提 Issue），我帮你把上限调高。

### Q: 我想换个日期跑，不想 11 号跑怎么办？

编辑文件 `.github/workflows/login.yaml`，找到这一行：

```yaml
- cron: "22 3 11 * *"
```

五个数字的含义：**分 时 日 月 星期**（用的是 UTC 时间，北京时间 = UTC + 8 小时）

比如：
- 每月 1 号跑：`"22 3 1 * *"`
- 每月 15 号跑：`"22 3 15 * *"`
- 每周一跑：`"22 3 * * 1"`

### Q: 脚本跑失败了（红叉）怎么办？

最常见的原因：
1. **密码填错了** → 编辑对应的 `WEBHOST_几`，改成正确密码
2. **账号已经被删了** → 去 WebHostMost 重新注册，然后更新 secret
3. **WebHostMost 网站暂时挂了** → 过几小时再手动跑一次试试（第 5 步）

### Q: 我的隐私安全吗？密码放在 GitHub 会不会被偷？

- Secrets 是**加密保存**的，日志里也不会显示
- 只有你自己能看到和修改
- 就算被偷，对方也只能拿到 WebHostMost 免费主机的登录权限（没啥值钱的），改个密码就行
